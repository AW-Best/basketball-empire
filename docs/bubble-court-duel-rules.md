# Hoopire Bubble Court 对战规则

更新：2026-10-18。当前体验基准是本地 DEMO01；不提交、不推送、不部署。本文合并此前规则，旧的“DEMO01 演出中可操作、砸筐同时落灰”描述由下面的新流程取代。

## 1. 核心循环与胜负

两人同时玩各自的泡泡龙：发射 → 同色消除 → 蓄能 → 主动 DUNK → 干扰对方 → 继续消除。DUNK 是可重复的局内攻击，不是胜利动画，扣一次不会结束比赛。

只有棋盘上实际存在的泡泡碰到底部危险线才判负，对手获胜；同一结算时刻双方触线则平局。清空棋盘、没有合法发射落点、DUNK 次数或动画结束均不直接判胜负。没有合法落点时提示换方向且不消耗球。

## 2. 开局、操作、消除

- 双方准备后倒数3秒开局。每人独立棋盘，相同起始布局和发球序列，各自按发射次数推进。
- 点按目标即发射；按住拖动瞄准、松手发射。可看瞄准和侧墙反弹路径。
- 连通3个或更多同色普通泡泡消除；失去顶部连接的泡泡掉落。
- 每个清除或掉落的普通泡泡 +10分、+16能量。积分独立保存；能量最多100，只存一条。
- 灰色干扰泡泡及DUNK清排不增加积分、能量或抵消额度。

## 3. DUNK 的共同规则

仅对局进行中、没有自己在途球、能量100且不在技能冷却/演出中可释放。点下原子扣除100能量，清掉自己最下面一个有球的整排，向对手排入最多4个干扰球；对手待落队列上限8个，超出不发，界面显示实际数量（0～4）。

DEMO01 满能量后可选：双手重扣、风车扣篮、黑洞暴扣、巨猫拍球。四招消耗和干扰强度相同；陨石、毛线、闪电只是表现。取消选招不扣能量，选招期间比赛继续。

## 4. DEMO01 最新攻击流程

| 阶段 | 画面与提示 | 比赛状态 |
| --- | --- | --- |
| 3秒预告 | 明确“你→对手”或“对手→你”；接收方显示“你将收到来自XX的大力灌篮”，3、2、1 | 双方仍可消除、防守抵消 |
| 扣篮起势（演出0～1秒） | 同一画面接近篮筐；接收方在屏幕中部横铺游戏容器全宽，发送方显示出击 | 双方比赛冻结，独立演出钟推进 |
| 接触与爆发（演出第1秒） | 手/球接触筐或巨爪击球时立即出现闪电，持续320ms；后三招前段正常推进 | 继续冻结 |
| 干扰飞出（第1.1秒起） | 后三招视觉球在1100ms内飞向目标；双手重扣仍750ms，与原画面重叠 | 继续冻结 |
| 完整命中（后三招第2.2秒） | 风车出球跨场、黑洞陨石落下、巨猫拍球到对面；原素材命中和干扰到达同步 | 灰球待结算，不重复创建 |
| 末端爆破慢动作（后三招2.2～3.1秒） | 用900ms持续播放源爆破后200ms，约0.22倍速；落点冲击圈和最多12道碎光缓慢展开，显示“命中爆破·慢动作” | 原动作和特效仍推进，不是静止等待 |
| 收势与短停（后三招3.1～4秒） | 3.1～3.5秒自然收势，3.5秒后才停留；最后400ms原层淡出。双手重扣仍保留120ms穿网跟随后停在筐边 | 不补发、不新开文字提示层 |
| 恢复 | 风车、黑洞、巨猫4秒，双手重扣3秒演出结束实际落灰；有在途球则等本球落定再加 | 比赛钟恢复，无追赶补算 |

后三种对战演出仅显示动作特写，不再绘制动作库里的左右两个示意泡泡龙棋盘或假能量条。风车跟随回环、扣筐与出球，命中后镜头回到落地人物；黑洞跟随入口穿越、出口扣筐及陨石落下；巨猫保留肉垫拍球、完整飞行和抬爪收势。镜头变化不改变真实棋盘，闪电原点使用相同投影。

风车、黑洞和巨猫整段演出4秒，双手重扣仍3秒；前面仍倒数3秒，从出招到恢复分别约7秒和6秒。后三招的新增时间用于最后命中前后和爆破，不整体拖慢蓄力、不延长静态尾帧。后三招必须播完出球、飞行、命中、动态爆破和收势才定格，不能在出球前或半途中截断。双手重扣使用真实砸筐接触帧，短暂跟随穿网后停住。独立动作库和完整sourceTime仍保留原动作对比。

普通消除、得分、蓄能与破解提示使用棋盘外顶部固定32px反馈栏；不在棋盘中央显示大字，提示出现/消失不改变棋盘尺寸。接收方演出横铺游戏容器全宽，以叠加层呈现，桌面不延伸到游戏区域之外。

不再出现独立 BREAK THEM 或 POWER BREAK 大字提示。保留小的来源方向、实际数量和灰球邻近三连破解说明。完整规则结算仍由对局状态控制，视觉飞球在末端等到结算，以免产生空白或重复加球。

接收方不可收起来跳过暂停；发送方可以收起自己的画面，但不会改变演出时钟。棋盘、发射区和底部按钮始终保持原尺寸和位置，只叠加演出。

若演出开始前已有在途球，恢复后先结算该球，再加入这包已展示的干扰，避免灰球抢占落点。这包干扰已经锁定，不再被本球抵消，也不会重新触发演出。

同刻双方攻击共同暂停，双方各自承担自己的实际干扰。同时演出按当次最长招式统一暂停，所有干扰统一在尾段结束后结算，避免一方提前恢复。

## 5. 防守与灰球处理

- 倒数期间，一次普通消除（包括随之掉落的普通球）每3个抵消1个待落干扰，向下取整，不跨次累计；先抵消最早的一包。
- 同刻先落球、消除、抵消，再处理压力/攻击。进入演出后数量锁定。
- 全部抵消时显示 BLOCK / 已化解，不会为了画面重新补出灰球或落点爆破；待落队列满时本招只清自己底排。
- 灰球不能按颜色配对，也不进入发球颜色池。钢灰内核、橙边裂纹和闪电图案用于识别。
- 在灰球旁边凑3个同色普通球消除，可连带击碎直接相邻的灰球；不连锁击碎第二层灰球。灰球悬空也会掉落。
- 灰球放入合法相连空位，不覆盖已有球或在途球预定落点。

## 6. 节奏、暂停和结算

DEMO01：顶部每35个比赛秒加一排；BOT开局延迟2.5秒、约每5个比赛秒发射、演出后休息8个比赛秒。BOT使用真实发射、消除蓄能与DUNK路径。

触底后立即停止规则推进和输入，保留触底棋盘：先停留180ms，再约900ms逐渐去色、压暗；约1.1秒后淡入“失败 / 胜利 / 平局”和“再来一局”。弹窗和按钮保持清晰可读。真人联网模式中，一方点“再来一局”发出邀请，自己等待，可取消；对方可“接受再战”或“暂不”。等待、暂不或取消时保留结算、最终棋盘及数据。只有另一方明确接受，才在原房间重置双方棋盘、积分、能量、旧攻击和所有过渡并倒数3秒；对手离线时等待重连后接受。首次开局仍需双方准备，DEMO01继续一键单人重开。减少动态效果设置使用稳定静态反馈。

切后台不会补发连击或重复加球。结束动画只控制显示，不延迟胜负规则本身。

## 7. 当前各入口的范围

- `/bubble-court/duel/?room=DEMO01`：独立单人模拟对手，每页各自开局，启用上述最新居中演出、慢放、爆发飞入和失败过渡。
- `/bubble-court/duel/design/`：同一攻击的发送/接收双视角设计对照，使用示意昵称和数据，可播放或定格爆发/飞入。
- 普通LAN房间：两手机同Wi-Fi通过房间码，服务器权威结算；目前保留基础双手动作、20秒压力、3秒倒数+0.8秒命中落灰，演出中可继续发射，尚未启用DEMO01的全局演出暂停。离线超过10秒冻结，重连平移截止时间，不追算压力。
- 早期 `duel-lab`、动作库、3D spike 作为历史本地比较保留，不代表当前规则。

“试玩充能”“试玩接招”“试玩失败”是本地测试入口：快速填满自己的能量、让模拟对手发起真实攻击、通过普通压力触底来体验失败过渡；不计入正式竞技设计。

## 8. 当前动作审阅流程

四种动作已拆到独立工作台 `http://localhost:8788/`，文件位于 `public/bubble-court/move-lab/`。无需对战服务、开局、充能或倒数，可直接切招、暂停、半速、拖动时间轴与看关键点。此页只表现动作和抽象干扰落点，不运行对局规则。

后续先只修改工作台内独立runtime快照，现有DEMO01保留当前版本；动作视觉确认后，再显式集成并验证攻防/结算。两套源暂时独立，避免动作打磨连带改变对战。
