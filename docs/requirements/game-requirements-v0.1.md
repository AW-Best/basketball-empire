# Basketball Empire 篮球棋盘游戏需求 v0.1

## 1. 文档状态

- 版本：v0.1
- 状态：需求草案
- 用途：私人、非营利网页游戏，供朋友在线游玩
- 支持人数：2至4人，主要针对4人实时在线房间设计

## 2. 游戏概念

玩家扮演篮球球队经理，通过签约球队、招募明星球员、建立完整赛区和收取比赛收益来累积资产。

棋盘移动采用回合制，所有玩家同时在线观看同一游戏状态。游戏不使用真实 NBA 球队 Logo、官方美术或 Panini 卡牌版式。

## 3. 胜利条件

### 3.1 快速模式（默认）

- 每位玩家完成6次经过“开赛”后触发结束。
- 触发后完成当前整轮，保证每位玩家的回合数相同。
- 计算积分、球队、明星球员、冠军阵容、交通通道、训练中心和颜色组奖励。
- 总资产最高者获胜。

### 3.2 可选模式

- 快速局：4圈，预计30分钟。
- 标准局：6圈，预计60分钟。
- 长局：8圈，预计90分钟。
- 淘汰局：只剩一名未破产玩家时结束。

### 3.3 平局顺序

1. 控制的球队数量。
2. 冠军阵容数量。
3. 剩余积分。
4. 掷骰决胜。

## 4. 棋盘结构

棋盘共40格：

| 格子类型 | 数量 |
| --- | ---: |
| 球队 | 22 |
| 交通通道 | 4 |
| 训练中心 | 2 |
| 球队运营 | 3 |
| 比赛时刻 | 3 |
| 特殊费用 | 2 |
| 角落 | 4 |

### 4.1 四个角落

- **开赛 Tip-Off**：经过或停留时获200积分，圈数加1。
- **替补席 Bench**：正常停留时只是参观；被罚入时需按规则离开。
- **更衣室 Locker Room**：基础规则下无事发生。
- **被罚下 Ejected!**：立即进入替补席，不领取开赛奖励，当前回合结束。

## 5. 球队与颜色组

- 22个可签约格均为虚构球队。
- 球队分成8个颜色组：2、3、3、3、3、3、3、2。
- 颜色可以代表赛区或竞争等级。
- 集齐同颜色全部球队后，基础比赛收益翻倍，并可为该组球队招募明星球员。

## 6. 球队签约

### 6.1 自由球队

玩家落在无人控制的球队时：

1. 系统显示球队信息、签约价格和基础比赛收益。
2. 玩家有20秒决定是否签约。
3. 选择签约时，按固定价格支付积分并取得球队。
4. 选择放弃或超时时，球队保持自由状态。

**本游戏不设在线竞拍，其他玩家不能在该回合出价或获得该球队。**

### 6.2 已控制球队

- 落在对手球队时，向球队经理支付对应比赛收益。
- 落在自己的球队时，无事发生。

## 7. 明星球员与冠军阵容

升级路线：

`Base Team → 1 Star → 2 Stars → 3 Stars → 4 Stars → Championship Lineup`

- 明星球员代替传统房屋。
- 冠军阵容代替传统酒店。
- 只有控制完整颜色组后才能招募明星。
- 同组球队必须平均发展，明星数量差不得超过1。
- 每支球队最多拥有4名明星，之后可升级为冠军阵容。
- 明星可按招募价的50%卖回系统。

## 8. 交通通道和训练中心

### 8.1 交通通道

暂定为东部专线、西部专线、全明星专线和总决赛专线。

| 控制数量 | 对手支付 |
| --- | ---: |
| 1 | 25 |
| 2 | 50 |
| 3 | 100 |
| 4 | 200 |

### 8.2 训练中心

- 进攻训练中心。
- 防守训练中心。
- 控制1个时，对手支付“骰子总点数 × 4”。
- 控制2个时，对手支付“骰子总点数 × 10”。

## 9. 球队运营与比赛时刻

### 9.1 球队运营卡

该牌堆以相对稳定的资源和管理事件为主。示例：

- 赞助合同：获50积分。
- 球衣销售：每位玩家向你支付10积分。
- 训练营：支付25积分。
- 社区公益赛：支付20积分。
- 赛季门票售罄：获100积分。
- 球员保险：获20积分。
- 阵容调整：免费将一名明星移至同颜色组的另一支球队，且调整后仍须满足平均发展。
- 替补许可：玩家保留此卡，可用于离开替补席。

### 9.2 比赛时刻卡

该牌堆以高波动、移动和比赛事件为主。示例：

- 快攻：前往下一支球队。
- 绝杀：获100积分。
- 失误：后退3格。
- 技术犯规：支付50积分。
- 被罚下：立即进入替补席。
- 三分命中：掷一颗骰子，获得“点数 × 20”积分。
- 客场之旅：前往任意交通通道。
- 加时赛：与左侧玩家各掷一颗骰子，胜者获50积分。
- 主场优势：下一次从你的球队收取双倍收益。
- 进攻犯规：当前回合立即结束。

## 10. 回合规则

1. 回合开始，启动45秒基础计时。
2. 当前玩家掷两颗骰子。
3. 棋子按总点数自动移动。
4. 系统执行落点效果。
5. 需要决策时提供20秒。
6. 进入最多30秒的管理阶段，可招募明星、抵押、解除抵押或发起交易。
7. 玩家点击结束回合，或计时结束后自动交给下一位玩家。

超时默认行为：

- 不签约球队。
- 不使用特殊卡。
- 拒绝交易。
- 必须支付的积分由系统自动支付。

## 11. 替补席

被罚入替补席的玩家可：

1. 支付50积分后正常行动。
2. 使用“替补许可”卡。
3. 尝试掷出双骰相同。

最多尝试3回合。第3次失败后必须支付50积分，并按本次骰子点数移动。停留期间仍可收取收益、交易、抵押和管理阵容。

## 12. 交易、抵押和破产

### 12.1 交易

- 只有当前玩家能发起新交易。
- 可交易球队、积分、交通通道和训练中心。
- 收到交易的玩家可接受、拒绝或还价。
- 每项交易有30秒响应时间。
- 每回合最多发起2次交易。
- 已配置明星的球队必须先卖回明星后才能交易。

### 12.2 抵押

- 没有明星的球队可抵押给系统。
- 抵押期间不能收取比赛收益。
- 解除抵押时支付抵押金额加10%。

### 12.3 破产

无法支付时，玩家可卖出明星、抵押球队或与其他玩家交易。仍无法支付则破产：

- 欠其他玩家：可转让资产交给债权玩家。
- 欠系统：资产回归系统并恢复自由状态。

## 13. 在线房间

### 13.1 房间流程

- 一名玩家创建房间并获得邀请码。
- 房间支持2至4人，不得超过4人。
- 玩家输入名称后加入，并选择准备。
- 全员准备后，房主可开始游戏。
- 开局后不允许新玩家加入。
- 系统随机决定回合顺序。

### 13.2 实时同步

- 最多4名玩家同时在线。
- 掷骰、移动和决策为回合制。
- 所有玩家实时看到骰子结果、棋子移动、积分和资产变化。
- 骰子结果必须由服务端统一生成。
- 非当前玩家可查看资产、聊天、发送表情和回应交易。

## 14. 玩家名称和头像

### 14.1 名称输入

- 进入房间时必须输入玩家名称。
- 名称长度为1至16个字符。
- 房间内不允许完全相同的名称。
- 应过滤 HTML、控制字符和不允许的内容。
- 游戏开始后不能修改名称。

### 14.2 字母头像

头像为带玩家颜色的圆形，最多显示2个字符。

- 一个单词：`Aaron` → `A`。
- 两个单词：`Aaron Wang` → `AW`。
- 三个及以上单词：使用第一个和最后一个单词，`Aaron James Wang` → `AW`。
- 连字符姓名：按名称主要部分提取，`Jean-Luc Picard` → `JP`。
- 中文名：显示前两个汉字，`王小明` → `王小`。
- 中英文混合：`Aaron 王` → `A王`。
- 忽略开头空格、标点和 Emoji。
- 缩写相同时，使用玩家专属颜色区分。

### 14.3 完整姓名显示

- 等待房间：头像、完整名称和准备状态。
- 玩家面板：头像、完整名称、积分和资产数量。
- 当前回合：高亮当前玩家的完整名称。
- 棋盘棋子：默认显示头像缩写，悬停或点击时显示完整名称。
- 交易、事件记录和结算排名：显示完整名称。
- 屏幕空间不足时可省略显示，但点击或悬停后必须显示全名。
- 系统始终保存完整名称，不保存截断后的文本。
- 掉线重连后恢复名称、头像缩写和玩家颜色。

## 15. 掉线、重连与暂停

### 15.1 掉线

- 玩家掉线后保留席位3分钟。
- 重连后恢复原有积分、球队、棋子位置、名称和头像。
- 掉线期间由系统执行安全默认操作。
- 超过3分钟未返回时，由 AI 临时接管；玩家返回后可重新控制。

### 15.2 暂停

- 任意玩家可申请暂停。
- 4人游戏需至少3人同意。
- 2至3人游戏需过半数同意。
- 每人每局最多申请2次，每次最长3分钟。

## 16. 验收标准

1. 2至4名玩家可通过邀请码加入同一房间。
2. 每位玩家可输入1至16个字符的完整名称。
3. 系统按规则生成1至2个字符的头像缩写，并在需要的界面显示完整名称。
4. 四位玩家能看到一致的骰子、棋子、积分、资产和回合状态。
5. 回合中只有当前玩家可掷骰和作出落点决策。
6. 落在自由球队时只能按固定价签约或放弃，不出现竞拍流程。
7. 玩家放弃签约或超时后，球队继续保持自由状态。
8. 系统可处理玩家掉线和重连，且不遗失游戏状态。
9. 达到设定圈数后，所有玩家完成相同回合数，系统正确计算和显示排名。
