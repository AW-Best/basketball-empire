# Sprint 010 — Lobby Rulebook

## Acceptance criteria

- The Create/Join screen prominently offers a Player Rulebook.
- The rulebook opens in the page without navigating away or losing entered form data.
- It accurately covers setup, turns, asset purchases, auctions, recruits, special blocks, bankruptcy, and winning.
- It states the implemented 10-minute match, 18-second turns, five-second auction, and PTS-only winner calculation.
- It is readable and dismissible on both desktop and mobile.

## Test case

- UI source contains the launch control, dialog, core current rules, open/close wiring, responsive styles, and cache-busted assets.
