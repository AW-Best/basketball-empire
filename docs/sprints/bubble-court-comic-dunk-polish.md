# 本地双人漫画 DUNK 动画优化

2026-10-17。用户授权优化当前 duel-lab 动画；保留此前不提交、不推送、不部署的限制。

## /sm AC

- 保持1.5s局内DUNK，800ms干扰预告、能量/清排/胜负均不变。
- 绝对时间轴分蓄势/加速举球/砸筐/60ms视觉停顿/抓筐/回落；动画不驱动规则。
- 球从上向下经过篮圈中心；释放后独立下落，抓筐手与篮圈保持相对固定，前后网遮挡正确。
- 网在球入筐后拉伸，阻尼回弹；只有球场镜头与漫画字震动，棋盘不动。
- 原创Canvas矢量，不加载外部模型/素材；DPR≤1.5、特效有固定上限。
- 低动态模式禁震动/快速推镜，仍表达攻击来源、DUNK和+4。
- 同时DUNK采用最新视觉事件覆盖，状态攻击均保留；不重播旧事件。
- 独立animation预览页共用同一renderer，重播/慢放/拖时间轴，重置无残留。
- 红绿单测运动连续性、入筐/抓筐、网回弹、低动态和渲染生命周期；实际320×568和390×844及真实双页DUNK验证。
