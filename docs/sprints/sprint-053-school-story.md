# Sprint 053: School story page

## Goal

Create a text-only English presentation page that a 14-year-old Year 8 student can use to explain how Basketball Empire went from an idea to a working online game.

## Acceptance criteria

- The story is written in natural first-person English suitable for speaking aloud.
- It covers the original idea, rule design, building with Codex, debugging, GitHub, domains and hosting, and checking daily visits.
- The page uses no images, SVGs, or picture elements.
- Sections work as full-screen speaking cards with keyboard navigation and progress.
- The page is readable on phones and printable as class notes.

## TDD checklist

- [x] RED: specify the content, text-only constraint, navigation, and print support.
- [x] GREEN: create and style the school presentation page.
- [x] Review the copy for an age-appropriate human voice.
- [x] Run all tests and verify the page locally.
