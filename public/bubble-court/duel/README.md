# Hoopire 双人泡泡对战

线上入口：https://hoopire.com/bubble-court/duel/ 。一人创建房间，另一人输入六位房间码或打开邀请链接；双方点准备后开打。线上两部手机可以使用不同网络。

点按发射，按住拖动瞄准、松手发射。三个同色消除，每个普通球加16能量、10分。满100点DUNK选择双手重扣、风车、黑洞或巨猫：自清最低一排，并向对方发送最多4个干扰球。每招强度相同。

先倒数3秒，期间可以正常消除，每次消除3个普通球抵消1个待落干扰球。正式演出暂停双方规则和输入，双手重扣3秒、其他招式4秒；完整命中和飞球后，剩余干扰球只落入一次，然后继续消除蓄能。干扰球通过相邻普通球消除或悬空掉落解除，不返还能量。每35秒双方加一排，只有泡泡触底才判负；本局结束后点“再来一局”邀请对手。邀请方显示等待对手，可取消；对方可接受再战或暂不。等待和拒绝时保留结算画面、棋盘和数据，只有双方同意后才在原房间清零并倒数3秒。对手离线时等待重连后明确接受。DEMO01仍一键重开。

对手离线超过10秒暂停，原标签页重连可恢复。线上房间使用Cloudflare Durable Object保存规则、身份和时钟，30分钟无活动后清理。服务器拒绝客户端充能、强制结束演出等测试指令。

## 单人试玩

大厅点击“单人试玩”或打开 `?room=DEMO01`。模拟对手自动准备、消除、蓄能并反击。每个页面独立练习，不创建服务器房间；可使用试玩充能快速体验大招。触底后点再来一局。

## 本地运行

项目根目录运行 `npm run dev:duel`（即 `node src/bubble-duel-server.mjs`），入口 `http://127.0.0.1:8780/bubble-court/duel/`。本地服务若供两部手机测试，需同Wi-Fi、使用电脑LAN地址并保持服务运行。本地默认也禁止真人房间充能；开发QA必须明确传入 `createBubbleServer({allowCharge:true})`，不要用于生产。

已确认的四招使用固定 `runtime-v2`，后续动作实验在 `/bubble-court/move-lab/` 独立修改，再明确接入。游戏画面为原创SVG/Canvas；真实扣篮视频仅作动作观察，不下载分发。实现、实玩及发布记录见 `docs/sprints/bubble-court-online-duel.md`。

## 代码与验证

当前玩家界面为英文。开发目录分工、固定动作快照、本地启动和发布注意事项见仓库根目录 `docs/bubble-court-code-map.md`。`npm run test:duel` 验证对战与动作；`npm test` 还包含旧单人3D游戏。提交GitHub不会自动部署。
